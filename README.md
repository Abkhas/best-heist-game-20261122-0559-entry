**The Aurelius Job** — a complete HTML5 heist game. One bright museum at noon: wear the docent uniform, blend into the tour groups, slip past three patrolling guards and two sweeping cameras, pocket the paintings and the Aurelius Diamond, crack the Crown Case, and slip out the staff exit before closing. Vision cones are danger, quiet corners are safety, skylight pools expose you, and a flashbulb, a jammer and a dropped ticket buy you seconds when the plan falls apart.

## Run it

```sh
cd game && python3 -m http.server 8000
# open http://localhost:8000 — WASD/arrows to move, 1/2/3 pick a tool, SPACE uses it, SHIFT strolls like a docent
```
