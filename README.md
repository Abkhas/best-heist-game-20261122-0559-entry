**The Midnight Vault** — a complete HTML5 heist game. One grand gallery at night: sneak past three patrolling guards and two sweeping wall cameras, pocket the paintings and the Starlight Gems, crack the vault, and slip out the exit before dawn. Vision cones are danger, shadows are safety, and smoke pellets and an EMP buy you seconds when the plan falls apart.

## Run it

```sh
cd game && python3 -m http.server 8000
# open http://localhost:8000 — WASD/arrows to move, 1/2 pick a tool, SPACE uses it
```
